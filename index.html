ABOUT THE PROJECT

Engineering intelligence through robotics.

TECHNO RC is a smart robotic car project built around the Arduino UNO. It explores wireless communication, motor control, distance measurement and autonomous navigation. The Android application provides an interface for controlling and connecting to the robot.

SYSTEM FEATURES

Four main app modules and intelligent robot functions.

🎮

Remote Controller

Control the robot's movement using the mobile application.

🎙️

Voice Controller

Send supported movement commands using voice input.

🔗

Connect to Car

Connect the Android app to the robot through Bluetooth.

⚙️

Settings

Access the application's configuration and preferences.

📡

Obstacle Detection

Ultrasonic sensing measures the distance to nearby objects.

🤖

Automatic Avoidance

The robot can stop, scan and choose an open direction when its programmed avoidance mode is active.

HARDWARE COMPONENTS

The electronics behind the robot.

Movement System

  • Arduino UNO — main controller
  • L298N — motor driver
  • DC gear motors — wheel movement
  • Robot chassis and wheels

Sensing & Communication

  • HC-05 — Bluetooth communication
  • HC-SR04 — ultrasonic distance sensor
  • SG90 — servo motor for sensor scanning
  • Buzzer — sound alert
  • Battery pack — power supply
Always check component voltage ratings, wiring polarity and motor power requirements before switching on the robot.

HOW TECHNO RC WORKS

From mobile command to real-world movement.

01 — The mobile application sends a command through Bluetooth.
02 — Arduino receives the command and controls the motor driver.
03 — The motors move the robot in the selected direction.
04 — The ultrasonic sensor checks the distance ahead.
05 — If an obstacle is detected, the programmed avoidance routine stops and scans for a safer path.
